# @blockexpanse/pdf-viewer-types

Shared type definitions (enums + constants) for the BlockExpanse PDF viewer.

Vendored from [`@toeverything/pdf-viewer-types`](https://github.com/toeverything/pdfium-builder) `v0.1.1`
(MPL-2.0), the PDFium viewer type package originally built for [AFFiNE](https://affine.pro/).
Shipped as a local workspace package so BlockExpanse is fully isolated from the upstream
`@toeverything/*` npm scope.
