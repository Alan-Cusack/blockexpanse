# Embed Blocks

These are blocks used to embed complex external content. The BlockExpanse framework allows for the quick creation of embed blocks through [embed helper](../../guide/working-with-block-tree#defining-new-blocks).

Existing embed blocks that support BlockExpanse document content include `EmbedLinkedDoc` and `EmbedSyncedDoc`, please refer to [link blocks](./link-blocks) for more details.
